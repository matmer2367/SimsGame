# Creating a Singleton File

File Name: S(Name).py

Every Singletion has to be defined as a **class**

Letter "S" is Needed as Prefix both as filename and classname.

In every File the last line of code has to look like this:

```python
instance: (ClassName) = None
```

# test_instances

After Creating the file, in the `test_instances.py` folder, create the assertion test for the class. All member attributes that are also Singletions has to be `not None`.
